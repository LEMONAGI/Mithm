# 미리듬 (Mirideum)

미리듬은 월경 주기를 단순히 기록하는 것을 넘어, 주기 속 몸의 변화를 이해하고 일정을 조율하도록 돕는 iOS 앱입니다.

Apple 건강 앱의 월경 기록을 바탕으로 현재 주기 흐름을 보여주고, 월경기, 난포기, 배란기, 황체기를 참고해 하루의 리듬을 조금 더 편안하게 바라볼 수 있게 돕습니다.

## 미리듬이 돕는 것

몸의 변화는 매번 같지 않고, 예측도 언제나 확정적일 수 없습니다. 미리듬은 기록을 바탕으로 예상 정보를 제공하되, 사용자가 자신의 상태를 더 잘 살피고 필요한 일정을 미리 조율할 수 있도록 차분한 참고점을 제공합니다.

- 최근 월경 기록을 바탕으로 다음 월경 예정일과 현재 phase를 보여줍니다.
- 기록된 월경일과 예상 배란기를 캘린더에서 함께 확인할 수 있습니다.
- Apple 건강 앱과 연결해 월경 기록을 한곳에서 관리합니다.
- 필요하면 월경과 배란 흐름을 iOS 캘린더에 내보낼 수 있습니다.

## 주요 기능

### Health 앱 연동

미리듬은 Apple 건강 앱의 월경 기록을 기반으로 동작합니다. 앱에서 추가하거나 수정한 월경 기록은 건강 앱에도 반영되며, 건강 앱에서 변경된 기록도 앱으로 다시 불러올 수 있습니다.

### 현재 phase 안내

홈 화면에서 현재 시점이 월경기, 난포기, 배란기, 황체기 중 어디에 가까운지 보여줍니다. 각 phase 설명은 진단이 아니라 최근 기록을 바탕으로 한 참고 정보입니다.

### 캘린더 확인

월별 캘린더에서 월경 기록과 예상 배란기를 한눈에 확인할 수 있습니다. 예측된 주기 길이와 월경 기간도 함께 표시해 흐름을 살펴보기 쉽게 구성했습니다.

### 월경 기록 관리

월경 시작과 종료를 기록하고, 앱에서 생성한 월경 기록은 나중에 수정하거나 삭제할 수 있습니다. 삭제한 기록은 건강 앱에서도 함께 제거됩니다.

### 캘린더 내보내기

설정에서 캘린더 내보내기를 켜면 월경과 배란 흐름을 iOS 캘린더에 반영할 수 있습니다. 한 번 연결한 뒤에는 기록 변경에 맞춰 캘린더 일정도 함께 관리합니다.

### 예측 방식과 주기 설정

사용자는 예측 방식과 기본 월경 주기, 월경 기간을 조정할 수 있습니다. 앱은 건강 앱 기록과 사용자가 입력한 정보를 참고해 예상 값을 계산합니다.

## 사용 흐름

1. 온보딩에서 건강 앱 접근 권한을 확인합니다.
2. 필요한 경우 월경 주기와 기간, 예측 방식을 설정합니다.
3. 홈에서 다음 월경 예정일과 현재 phase를 확인합니다.
4. 월경이 시작되거나 끝났을 때 날짜를 선택해 기록합니다.
5. 캘린더에서 기록과 예상 흐름을 살펴봅니다.
6. 원하면 설정에서 iOS 캘린더 내보내기를 켭니다.

## 데이터와 권한

미리듬에서 월경 기록의 기준이 되는 데이터는 Apple 건강 앱입니다. 별도의 월경 기록 저장소를 운영하지 않고, 건강 앱의 기록을 바탕으로 주기와 phase를 계산합니다.

건강 데이터와 캘린더 접근 권한은 사용자가 직접 허용한 범위 안에서만 사용됩니다. 예측 결과는 확정된 정보가 아니라 최근 기록을 바탕으로 계산한 참고 정보이며, 의학적 진단이나 치료 판단을 대신하지 않습니다.

## 기술 정보

- 플랫폼: iOS
- UI: SwiftUI
- 시스템 연동: HealthKit, EventKit
- 아키텍처: Clean Architecture + MVVM
- 외부 의존성: 없음
