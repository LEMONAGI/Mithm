# Mithm Product Context

이 문서는 Mithm의 제품 의도와 사용자 경험 판단 기준을 정리한다. UI 문구, 화면 흐름, 상태 표현을 바꿀 때 함께 읽는다.

## 제품 목적

Mithm은 사용자가 월경 주기를 단순히 기록하는 것을 넘어, 몸의 변화를 이해하고 일정을 조율하도록 돕는 앱이다.

- 월경 기록을 HealthKit과 연결한다.
- 월경기, 난포기, 배란기, 황체기 흐름을 사용자가 이해하기 쉽게 보여준다.
- 예측은 확정이 아니라 조율을 돕는 참고 정보로 다룬다.

## 사용자 경험 원칙

- 건강 정보를 과도하게 단정하지 않는다.
- 예측은 "가능성", "예상", "참고"의 톤으로 표현한다.
- 사용자가 불안해질 수 있는 경고성 문구를 남발하지 않는다.
- 기록과 예측을 구분해서 보여준다.
- 사용자가 Apple Health에서 수정한 데이터가 앱에 반영될 수 있음을 흐름상 자연스럽게 고려한다.

## 문구 톤

- 사용자에게 보이는 문구는 한국어로 작성한다.
- 차분하고 다정하지만 과하게 감성적이지 않게 쓴다.
- 의학적 진단처럼 보이는 표현은 피한다.
- 앱이 사용자의 몸을 대신 판단한다는 인상을 주지 않는다.

예:
- 좋은 방향: "예상 월경 시작일이에요", "최근 기록을 바탕으로 계산했어요"
- 피할 방향: "정확한 월경 시작일입니다", "몸 상태가 비정상입니다"

## UI 판단 기준

- 핵심 정보는 한눈에 읽히게 한다.
- 주기와 Phase 정보는 상태, 기간, 근거가 구분되게 표시한다.
- 설정과 기록 수정 흐름은 사용자가 되돌릴 수 있다는 느낌을 준다.
- 건강 데이터 권한 흐름은 사용자가 왜 필요한지 이해할 수 있게 한다.

## 비목표

- 의학적 진단 제공
- HealthKit 외 별도 의료 데이터 저장소 운영
- 복잡한 소셜/커뮤니티 기능
- 외부 분석 SDK 또는 광고 SDK 도입
